❓ Was bedeutet x?

x ist einfach eine Zahl, die wir noch nicht kennen. Steht eine Zahl davor, wird malgerechnet.

3x bedeutet 3 · x

🧲 Was darf zusammen?

Gleiche Buchstaben darfst du zusammenzählen. Verschiedene Buchstaben bleiben getrennt.

3x + 5x = 8x

📦 Zahl vor einer Klammer?

Nimm die Zahl mit jedem Teil in der Klammer mal. Wirklich mit jedem.

3(x + 2) = 3x + 6

🌪️ Minus vor einer Klammer?

Alle Zeichen in der Klammer drehen sich um: Plus wird Minus und Minus wird Plus.

−(x − 4) = −x + 4

🎟️ „Für x = 4“?

Ersetze jedes x durch eine 4. Danach rechnest du ganz normal aus.

2x + 3 → 2 · 4 + 3 = 11

⚡ Was bedeutet x²?

x² bedeutet x · x. Bei x³ wird x dreimal miteinander malgenommen.

x² · x³ = (x · x) · (x · x · x)
= x · x · x · x · x = x⁵
